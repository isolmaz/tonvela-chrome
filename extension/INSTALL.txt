TONVELA — CHROME VOLUME EXTENSION / 1.4.0

INSTALL
1. Extract the ZIP into a permanent folder.
2. Type chrome://extensions in the Chrome address bar.
3. Turn on Developer mode in the top right.
4. Click Load unpacked.
5. Select the folder that contains this file and manifest.json.
6. Open a video. Pin Tonvela from the Chrome puzzle icon.
7. Open Tonvela and drag the volume bar or pick 100%, 200% or 400%.

The ZIP can't be installed by dragging it into Chrome. Extract it first.
Don't delete or move the folder after installing.
No account or extra software is needed. Requires Chrome 116+.

UPDATING
Press Back to original sound on open tabs first. Extract the new ZIP. You
can replace the extension files in your existing folder with the new ones
and press Reload on chrome://extensions. Reloading the same extension keeps
your preferences.

BASIC USE
Tonvela starts on a tab as soon as you change its sound: the volume bar,
the 100% / 200% / 400% buttons or Listening mode. Back to original sound
returns the tab to its own audio. Closing the window doesn't stop
processing; it ends when the tab closes.

Listening mode offers Normal, Steady, Speech, Night, Music and the
experimental Voice only. "Keep this level" (under the mode list): play a
comfortable part for 1–2 seconds and press the button. The last measured
level becomes the target; silence is ignored. Undo restores the previous
settings.

The gear opens Settings: output device, mono sound, left / right balance,
hearing protection, remembering settings for each site, appearance and
language (English, Türkçe, Español, Português, العربية). Until you choose a
language, Tonvela follows Chrome's language.

FULLY LOCAL
All code and the speech model are inside the ZIP. No model downloads, APIs,
servers or recording. The microphone is only asked for, once and if you
choose to, so Chrome shows output device names; it is closed right away.
Preferences stay in the browser; no cloud sync.

EXPERIMENTAL MODE
Voice only tries to suppress background sound with the local GTCRN neural
network. It doesn't promise perfect music/effects removal; output is mono.
The model runs at 16 kHz outside the audio thread and adds about 50 ms of
delay. If your computer can't keep up, the window shows a warning.
